# OGraf Studio 0.15

Released: 2026-09-08

This release makes canvas editing clearer and keeps path editing active during background clicks.

- Removed the blue data-binding dots from canvas artwork. Bindings remain available in
  **Properties → Data Bindings**, with no change to playback data.
- Clicking blank canvas during **Edit as path** keeps the path handles visible and preserves
  keyboard nudging. **Done** or **Escape** exits; normal deselection resumes afterward.
- Updated MCP capabilities, public usage guidance and the authoring skill for these behaviors.

## Downloads

Single-file servers are available for Windows x64, macOS Intel/Apple Silicon and Linux x64/ARM64.
Run the executable and open http://127.0.0.1:4318/. No Node.js, npm or Bun installation is needed.
On macOS/Linux, first run `chmod +x <downloaded-file>`.

The release includes the authoring skill ZIP, SHA-256 checksums and a build manifest. Windows and
macOS executables are unsigned; macOS builds are not notarized. macOS and ARM64 builds are
cross-compiled and structurally verified; native execution on those platforms remains unverified.
