# OGraf Studio 0.16

Released: 2026-09-08

Preview & Export now supports fullscreen presentation with keyboard step controls.

- **Fullscreen** replaces **Picture only** in the detached preview window and is also available
  in the docked pane. The graphic fills the display proportionally, without editor controls.
- Move the detached preview window to the desired display before entering fullscreen. Keep the
  main Studio window open to continue editing and controlling the shared project.
- **Space / Right Arrow** advances to the next OGraf step; **Left Arrow** goes to the previous
  step. Preview navigation does not operate the editing Timeline. Data inputs retain normal keys.
- **Escape** exits fullscreen. Entering and leaving fullscreen preserves the current graphic and
  playback position. Editing the graphic still rebuilds the preview and resets playback.
- Updated public usage and authoring-skill guidance.

## Downloads

Single-file servers are available for Windows x64, macOS Intel/Apple Silicon and Linux x64/ARM64.
Run the executable and open http://127.0.0.1:4318/. No Node.js, npm or Bun installation is needed.
On macOS/Linux, first run `chmod +x <downloaded-file>`.

The release includes the authoring skill ZIP, SHA-256 checksums and a build manifest. Windows and
macOS executables are unsigned; macOS builds are not notarized. macOS and ARM64 builds are
cross-compiled and structurally verified; native execution on those platforms remains unverified.
