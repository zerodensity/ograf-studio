# OGraf Studio 0.02

Released: 2026-08-24

OGraf Studio 0.02 strengthens production authoring, preview reliability, resource portability, and
the everyday timeline workflow while preserving the same deterministic OGraf runtime and certified
output boundary.

## New features

- Added disposable browser certification realms and a serialized browser work queue for exact
  certification, PNG capture, animation strips, and text measurement.
- Expanded Resources into a complete image, font, and source-attachment workflow with payload
  deduplication, original-file metadata, package paths, usage-aware removal, font descriptors, and
  optional license packaging.
- Added immutable real-time, non-real-time, and dual-mode export profiles. Profile selection derives
  output capabilities, graphic identity, and filenames without mutating the editable project.
- Added paired frame/millisecond timing controls with fractional-frame detection and explicit
  down/nearest/up rounding choices.
- Added broadcast typography controls for line height, tracking, case, vertical alignment, baseline
  shift, minimum shrink size, and overflow policy.
- Added source-design overlays and advisory broadcast QA, including browser-rendered replacement-text
  stress checks.

## Preview and timeline workflow

- Simplified OGraf Preview to automatically load, apply data changes, refresh after template edits,
  and dispose replaced runtime instances.
- Retained standard Previous Step, Next Step, absolute Go to Step, and Take Out controls while
  removing redundant manual lifecycle buttons.
- Removed the obsolete Lower Third Demo command from the production menubar.
- Reduced the Timeline toolbar to transport, Step/key creation, compact time, and one zoom control.
- Made the Keyframe Editor contextual and moved Bézier curves, whole-track transforms, and local
  loops into progressive-disclosure sections.
- Added keyboard-accessible lifecycle markers and property keys, configurable whole-track scaling,
  and context-menu group colour editing.

## Runtime and authoring consistency

- Kept editor preview, browser capture, exact certification, and exported playback on the shared
  compiled timeline and DOM/runtime semantics.
- Extended project document migration and validation for the new typography and resource metadata.
- Updated MCP capability schemas and the `ograf-authoring` skill for the current authoring model.
- Updated README, architecture, roadmap, status, and next-release documentation.

## Validation

- 219 automated tests pass across 48 files.
- Formatting, lint, TypeScript checks, runtime build, editor production build, and workspace builds
  pass.
- The simplified timeline, contextual editors, group controls, and OGraf Preview behavior were
  exercised in the live browser with no console errors.

## Current boundaries

- Arbitrary third-party OGraf JavaScript import remains intentionally lossy and is never executed.
- Lottie support remains the self-contained, canvas-only, continuously looped initial profile.
- Large self-contained asset registries can still reach browser-storage limits.
- The production editor build reports a non-blocking large JavaScript chunk warning.
