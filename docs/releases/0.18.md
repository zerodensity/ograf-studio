# OGraf Studio 0.18

Unreleased

This release fixes embedded font rendering in exported OGraf packages.

- Packaged fonts now render in playout. The runtime previously declared `@font-face` rules only
  inside the Graphic's shadow root, which browsers ignore, so text silently fell back to the next
  family in its font stack. Faces are now also registered on the owning document through the
  `FontFace` API, and `load()` waits for them to settle before reporting ready.
- Fonts with a custom package path (for example `fonts/Brand-Bold.ttf`) now resolve relative to
  the exported module, as `assets/` paths already did. Previously they resolved against the host
  page, which broke when a player loaded the package from another directory.
- A face that fails to load no longer blocks `load()`; text uses the authored fallback stack.

Existing projects need no changes. Re-export packages that embed fonts to pick up the fix.
