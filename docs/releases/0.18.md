# OGraf Studio 0.18

Released: 2026-09-10

- AI Assistant supports Codex, multiple annotated canvas selections, and browser voice dictation.
- Accepted AI changes appear in History and can be undone; progress uses one updating status line.
- Save templates with a transparent PNG thumbnail from a chosen frame or the first OGraf step.
  Thumbnail filenames use the project ID: `<id>_thumb.png`.
- Fixed thumbnail rendering for embedded images supplied through data bindings.
- Separate OGS, JSON, and All files filters in the Open dialog; Pause at Steps is enabled by default.
- Updated MCP contracts, authoring skills, and user documentation.

## Windows download

Download `OGrafStudioServer.exe` for Windows x64. It includes Studio and the MCP server in one
executable; Node.js, npm, and Bun are not required. Run it and open http://127.0.0.1:4318/.
The executable is unsigned. Codex integration requires a separately installed and signed-in Codex.

This release provides a Windows executable only.
