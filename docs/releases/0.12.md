# OGraf Studio 0.12

Released: 2026-09-04

OGraf Studio 0.12 improves media authoring, multi-monitor workflows, Timeline clarity and reversible
brand styling. The release includes single-file servers for Windows x64, macOS Intel/Apple Silicon
and Linux x64/ARM64.

## Media authoring and reusable backgrounds

- Add Image opens a visual picker for direct upload or reuse from the project library. Images may
  also be dropped onto the canvas, retain intrinsic aspect ratio and fit inside the composition.
- Resources exposes image thumbnails with Add to canvas. Properties previews the current image and
  replaces it without discarding layer placement, animation or bindings.
- Existing images, reusable components and the procedural Graphite background remain editable and
  may be composed into lower thirds or other templates.

## Brand Kit and motion backgrounds

- Applying a style pack now updates existing color controls, GDD defaults, gradients, reflections,
  highlights and shared lighting while preserving tonal ratios, alpha, masks and motion.
- Editing a parent palette token propagates through linked custom controls and runtime field
  defaults. Playback data remains authoritative.
- Remove applied pack restores the recorded pre-pack fonts, colors, bindings, field defaults and
  timing. Repeated pack switches derive from the original baseline rather than compounding shades.
- Shared Looping Pattern lighting coordinates sweep timing, phase, intensity, glow strength and
  softness while retaining per-layer speed variation and original curves.

## Interface and multi-monitor workflow

- Every tool pane can open in a separate browser window and move to another monitor. Detached panes
  share project state, selection, undo history, form drafts and the single MCP connection. Closing
  the window or choosing Dock back restores the original pane location.
- Detached Preview includes Picture only mode. Timeline shortcuts, menus, image dialogs, numeric
  scrubbing, imported fonts and property resizing follow the pane into its browser window.
- Property label/value columns are draggable and remembered per pane. Left labels have contextual
  tooltips and accessible descriptions for semantic, layout, text, mask, effect, pattern, lighting,
  Brand Kit and runtime-data controls.
- Timeline adds clear previous/next-frame controls and focused Left/Right stepping. Alt+Arrow retains
  keyframe nudging; Alt-hover reveals detailed track metadata without crowding the lanes.
- Transition duration controls use compact `f`/`ms` labels and viewport-safe rounding choices.
  Folder rows and animation spans use flat fills for clearer keys and markers.

## AI authoring and document compatibility

- MCP operations and generated guidance understand shared lighting, reversible style-pack palettes,
  image-first insertion, component reuse and current Timeline behavior.
- The external authoring skill documents color routing, shared lighting and detached-window session
  ownership. A second full editor is no longer suggested for multi-monitor use.
- Source document version 31 migrates older projects at the load boundary. Restore and palette-link
  metadata are authoring-only; compiled graphics contain ordinary materialized colors and fields.

## Lottie compatibility

- Self-contained Lottie layers support looping Canvas playback.
- Known resize/color, zero-sized-canvas, image-readiness and source in-point issues remain in this
  version. They are addressed in 0.13.
- Expressions, external assets, marker/segment control and dotLottie are outside this profile.

## Verification and boundaries

- The full repository gate covers generated MCP contracts and prompts, formatting, lint, typechecks,
  unit/integration tests and production builds. Exact final totals are recorded in the release
  build manifest.
- All five artifacts receive binary-format, architecture/content and SHA-256 checks. Windows and
  Linux x64 receive startup/HTTP smoke checks; Windows also receives MCP and browser/runtime checks.
- macOS and ARM64 binaries are cross-compiled and structurally checked; native execution remains
  unverified. Windows is unsigned; macOS binaries are unsigned and not notarized.
- Save/export performs automated OGraf conformance checks. This is not EBU certification or a claim
  of compatibility with every third-party renderer.
- The main Studio window must remain open while panes are detached. Embedded browser hosts may open
  tabs; regular Edge/Chrome windows provide OS-level multi-monitor placement.
