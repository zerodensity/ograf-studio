# OGraf Studio 0.14

Released: 2026-09-05

OGraf Studio 0.14 adds visual vector point editing and matching AI authoring operations.

## Edit as path

- Select a rectangle, rounded rectangle, ellipse or existing path, then choose Edit as path in
  Properties or the canvas context menu. Drag anchors and incoming/outgoing curve handles directly
  on the canvas, including on rotated and nonuniformly resized layers.
- Add Point splits the following segment without changing its curve. Remove Point, Smooth and
  Corner reshape the contour. Shift constrains dragging; arrows nudge, Shift+Arrow moves ten units,
  and Alt adjusts a handle independently. Escape cancels a drag or exits; Done exits point mode.
- Each finished drag is one undo step. Conversion retains layer identity, compatible paint,
  effects, bindings, relationships, transform keys and loops. Shape edits apply across the animation.
- Edited paths can extend outside the original viewBox. Preview and exported runtime use the same
  expanded curve bounds, while keeping authored transform tracks fixed. Gradients span the expanded
  content box. Existing unedited paths retain their prior clipping behavior.

## MCP and authoring guidance

- The MCP server advertises version 0.14.0. `edit_path` supports conversion, anchor movement,
  handle changes, subdivision, removal, smoothing and corners through revision-checked batches.
- Scene inspection exposes SVG data and contour nodes. Every point edit checks `expectedD` against
  current geometry; re-read indices after insertion/removal. Unexpected action fields and edits to
  locked layers fail without partially applying a batch.
- Capabilities document exact parameters and limits. The repository and installed authoring skill,
  portable skill archive, generated MCP contracts and in-app prompt contain the updated workflow.
  Existing context budgets remain unchanged.

## Verification and boundaries

- The full repository gate covers 541 tests across 103 files, generated contracts/prompts,
  formatting, lint, typechecks and production builds. Exact source and artifact identities and
  release smoke-test results are recorded in the build manifest.
- All five binaries receive format, architecture, embedded-content and hash checks. Windows and
  Linux x64 receive startup/HTTP checks; Windows additionally exercises MCP and browser export.
- macOS and ARM64 binaries are cross-compiled and structurally checked; native execution remains
  unverified. Windows is unsigned; macOS binaries are unsigned and not notarized.
- Unlink corner-radius tokens before conversion. Rounded rectangles clipping children require a
  separate mask or disabling child clipping. Converted corners/strokes scale with the path box.
  Arcs become cubic approximations. Limits are 4096 anchors and 500000 SVG characters.
- This version edits static geometry. Vertex morphing, text outlines, image tracing, pattern-symbol
  editing and Lottie decomposition remain outside its scope.
- Save/export uses automated OGraf conformance checks; this is not EBU certification or universal
  third-party renderer compatibility.
