# OGraf Studio 0.01

Released: 2026-08-23

OGraf Studio 0.01 is the first named release of the visual EBU OGraf authoring environment and its
optional MCP authoring server.

## New features

- Renamed the product to **OGraf Studio** across the application and current documentation.
- Added state-aware exits that animate directly from the active Step to End.
- Added multiple independent property bindings per layer.
- Closed structural editor/MCP parity gaps for lifecycle markers, canvas groups, reusable
  components, custom actions, and reference-safe asset removal.
- Added reusable component snapshots with independently editable inserted instances.
- Added portable Photoshop SVG bundle import with companion CSS, images, and fonts.

## Also included

- Deterministic looped Lottie JSON layers for editor scrubbing, realtime playback, non-realtime
  seeking, validation, export, and MCP authoring.
- Document-v12 migration for reusable components and multi-binding compatibility.
- Updated README, architecture, roadmap, status, templates, and `ograf-authoring` Skill guidance.

## Validation

- 212 automated tests pass across 46 files.
- Formatting, lint, TypeScript checks, runtime build, editor production build, and workspace builds
  pass.
- The editor and MCP bridge were tested together at the release commit.

## Current boundaries

- Photoshop SVG bundles remain portable image assets; arbitrary Photoshop/rasterized content is not
  decomposed into editable scene layers.
- Inserted reusable-component instances are deliberately independent. Live master-instance syncing
  and per-instance override inheritance are future work.
- The production editor build reports a non-blocking large JavaScript chunk warning.
