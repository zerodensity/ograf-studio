# OGraf Studio 0.33.0

This release adds author-chosen export keys, frame cues, and a built-in cue log. Standalone builds
also include the matching OGraf authoring skill.

## Export keys and frame cues

- Set an **Export key** in Properties to identify a layer in single-template and coordinated exports.
  JavaScript can find that layer through `graphic.instances[instanceId].layers[exportKey]`.
- Use **+ Cue** on the Timeline to name a cue at a specific frame and attach an optional JSON payload.
  The exported graphic emits `ograf-studio-cue` during forward real-time playback. Coordinated cues
  identify the template and lane as well as the live instance.
- Open **Frame Cue Log** in Studio’s **Preview & Export** pane to see the cues as they fire. In exported
  HTML previews, press **D** to show the controls. Re-export an existing project to add these features
  to its playback files.

## Authoring and editor updates

- Use `--print-setup-prompt` to print AI client setup instructions and `--export-skill <path>` to save the
  authoring skill embedded in the standalone executable.
- **Save** writes to the active template or template set file. **Save As…** lets you choose a new
  destination, and **Save Template Copy…** saves a separate editable copy.
- Text boxes set to **Clip** support horizontal and vertical clipping margins. With **Auto Size**,
  a nonzero margin follows the measured text box when bound data changes.

## Downloads and startup

- `OGrafStudioServer.exe` for Windows x64.
- `OGrafStudioServer-linux-x64` for Linux x64.
- `OGrafStudioServer-linux-arm64` for Linux ARM64.
- `ograf-authoring.zip` for the matching authoring skill.
- `RELEASE-MANIFEST.json` and `SHA256SUMS.txt` for the source revision and artifact verification.

Run the executable and open **http://127.0.0.1:4318/**. On Linux, make the downloaded file executable
with `chmod +x <filename>` first. The Windows executable is unsigned. The release workflow checks
startup on Windows and Linux x64 and verifies the binary format and architecture on Linux ARM64.

See the [User Guide](https://github.com/zerodensity/ograf-studio/blob/stable/docs/USER_GUIDE.md) and
