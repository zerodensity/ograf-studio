# OGraf Studio 0.32.0

This release improves editable PSD and SVG imports and gives template authors control over which
data fields are declared as Nodos inputs.

## Editable design imports

- **Resources → Images → Import PSD** keeps supported solid rectangles and simple text editable.
  Layers retain their Photoshop stacking order within groups and across the document. Pixel artwork
  remains an image layer. PSDs that require unsupported compositing can still use the saved merged
  image.
- **Import editable SVG** accepts common layer metadata, preserves simple inline paints and numeric
  letter spacing, and keeps supported artwork editable. Unsupported objects such as paths with
  rounded stroke caps can be preserved as separate images.

## Nodos inputs

- In **Data**, choose which fields to declare as ElectroNode inputs independently of their
  exposure to OGraf playout. New templates start with no data fields selected for Nodos.
- Older templates retain their previous declarations. Supported OGraf imports retain the
  selected inputs and their native type information.

## Downloads and startup

- `OGrafStudioServer.exe` for Windows x64.
- `OGrafStudioServer-linux-x64` for Linux x64.
- `OGrafStudioServer-linux-arm64` for Linux ARM64.
- `ograf-authoring.zip` for the matching authoring skill.
- `RELEASE-MANIFEST.json` and `SHA256SUMS.txt` for the source revision and artifact verification.

Run the executable and open **http://127.0.0.1:4318/**. On Linux, make the downloaded file
executable with `chmod +x <filename>` first. Windows builds are unsigned. The release workflow
checks startup on Windows and Linux x64. Linux ARM64 is checked for binary format and architecture.

See the [User Guide](https://github.com/zerodensity/ograf-studio/blob/stable/docs/USER_GUIDE.md) and
[development guide](https://github.com/zerodensity/ograf-studio/blob/stable/docs/DEVELOPMENT.md).
