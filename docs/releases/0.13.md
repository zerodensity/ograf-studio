# OGraf Studio 0.13

Released: 2026-09-04

OGraf Studio 0.13 hardens Lottie playback and makes everyday layer creation safer and faster. The
release includes single-file servers for Windows x64, macOS Intel/Apple Silicon and Linux x64/ARM64.

## Lottie runtime reliability

- Lottie renders into an adapter-owned positive Canvas and avoids lottie-web's destructive resize
  path. Gradients, gradient strokes, mattes and rounded-corner artwork retain their color;
  hidden/detached initialization no longer creates zero-sized matte buffers.
- `load()` and browser captures await embedded images, fonts, item construction and the first Canvas
  frame. Images are predecoded; data, load, render and timeout failures surface explicitly.
  Segmented documents, invalid image assets and unsupported luma mattes fail early.
- Nonzero source in-points map correctly to the player's relative seek API. Realtime layers share
  one clock; changed non-realtime targets rebuild and await a fresh player for byte-repeatable
  output.
- Persistent playback sizes backing canvases from maximum authored bounds within a DPR-adjusted
  allocation cap. Certification verifies every expected Canvas and compares SHA-256 pixel
  signatures across a non-period-aligned backward/return seek.
- Expanded regression checks cover Lottie rendering, repeatable seeking and exported playback.

## Safer authoring defaults

- Startup hydration completes before the editor mounts. Launch, New, open/import and template
  replacement reset transport to frame 0 and select the Start lifecycle state.
- Placing a fresh layer at frame 0 updates each still-static transform property across its equal
  Start/Step/End compatibility keys. Deliberately animated properties and edits at nonzero frames
  remain frame-scoped.
- New rectangles and ellipses start at 200 × 200, producing a square and circle respectively.
  Explicit dimensions and later free resizing remain independent.
- Selected-layer Properties puts Name/Z order, Transform/Alpha/easing and element-specific
  appearance before Brand Kit, effects, compositing, layout, bindings and semantic metadata.

## Exact duplication

- Ctrl/Cmd+D, Edit → Duplicate and canvas Duplicate create an exact-position copy and select it.
  Ordinary Paste retains its visible 20 px offset.
- Persistent groups, parents, masks, keys, loops and complete linked component instances receive
  fresh safe IDs, including nested bound-field nodes. Partial linked copies detach instead of
  retaining invalid relationships.
- Copies form one contiguous block immediately above the frontmost selected source, and each
  command is one undo step. New/open clears project-scoped clipboard state so composition-local
  references cannot leak between projects.

## AI authoring and compatibility

- MCP capabilities describe the supported Lottie Canvas, readiness and seek profile. Scene
  inspection returns derived validity, warnings, dimensions, rate and in/out timing for each Lottie
  layer.
- The external `ograf-authoring` skill and generated in-app guidance cover self-contained Lottie
  inputs, representative-frame inspection, backward seeking, certification and target-renderer
  limits. MCP rectangle and ellipse defaults match the 200 × 200 editor defaults. Generated MCP
  contract metadata now comes from the connected server handshake, so its advertised version stays
  aligned with the released server.
- Source document version remains 31. Existing projects migrate at the load boundary; this release
  introduces no new persisted schema version.
- Product and MCP server versions are 0.13 / 0.13.0; Windows file metadata is 0.13.0.0.

## Verification and boundaries

- The repository verification gate covers 529 tests across 102 files, generated contracts/prompts,
  formatting, lint, typechecks and production builds.
- Windows and Linux x64 receive startup/HTTP smoke checks; Windows also exercises MCP and browser
  rendering/export. All five artifacts receive binary-format, architecture/content and hash checks.
- macOS and ARM64 binaries are cross-compiled and structurally checked; native execution on those
  platforms remains unverified. Windows is unsigned; macOS builds are unsigned and not notarized.
- Expressions, external image/font paths, segmented documents, invalid embedded images, luma
  mattes, marker control, one-shot playback, dynamic internal text, dotLottie and renderer selection
  remain outside the supported Lottie profile. Target HbbTV/Lino/device verification is pending.
- Save/export uses automated OGraf conformance checks. These are not EBU certification or a claim
  of compatibility with every third-party broadcast renderer.
