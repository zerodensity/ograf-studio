# OGraf Studio 0.31.0

OGraf Studio 0.31 saves the prompts behind AI-authored templates and gives exports a single
workflow for templates and template sets.

## AI authoring

- Studio’s built-in AI Assistant records accepted user prompts automatically. In the **Saved
  prompts** section, use **Copy** to copy the full text or **Use prompt** to load it into the draft.
  These actions work without an AI provider configured.
- Prompt history stays with each template in `.ogs` files, OGraf ZIP manifests, and standalone HTML.
  In the HTML preview, open the controls and expand **Authoring prompts** to read it.
- External MCP clients now supply `originalPrompt` when creating or resetting a project and when
  creating, duplicating, or pasting a template in a set. When starting from an open blank template,
  include `set_project_metadata.authoringPrompt` with the first layer or recipe batch. Clients and
  scripts using the previous inputs need to refresh the tool schema and send the original user
  text. Studio checks that text is supplied. The MCP client has access to the conversation it came
  from. See the [AI authoring guide](https://github.com/zerodensity/ograf-studio/blob/stable/docs/AI_AUTHORING.md).

## Export and preview

- **File → Export…** handles both the current template and a template set. Export a standalone HTML
  preview or an OGraf ZIP independently, or choose **Both files** where supported. Save your
  preferred scope and format in **Preferences → OGraf Studio → Export**.
- Template set exports show progress while Studio prepares and checks the files. Use **Cancel**
  or **Escape** during preparation. Once checks pass, save or download the prepared output. The
  **Save Certified Export…** action can reuse the prepared bytes.
- Standalone HTML starts with its controls hidden. Right-click or press **D** to show them.
  Entering fullscreen hides the controls and FPS overlay for a clear preview.
- Invalid chart data from a connection is rejected before it reaches the chart. Shader canvas
  checks use an independent snapshot for repeat-frame comparisons in non-real-time output.
  Templates with an enabled external connection and authored dual modes initially use the
  **Real-time playout** profile. Choose **Dual** or **Non-real-time render** for scheduled rendering.

## Downloads and startup

- `OGrafStudioServer.exe` for Windows x64.
- `OGrafStudioServer-linux-x64` for Linux x64.
- `OGrafStudioServer-linux-arm64` for Linux ARM64.
- `ograf-authoring.zip` for the matching authoring skill.
- `RELEASE-MANIFEST.json` and `SHA256SUMS.txt` for the source revision and artifact verification.

Run the executable and open **http://127.0.0.1:4318/**. On Linux, make the downloaded file
executable with `chmod +x <filename>` first. Windows builds are unsigned. The release workflow
checks startup on Windows and Linux x64. Linux ARM64 is checked for binary format and architecture.

For workflows and compatibility details, see the [User Guide](https://github.com/zerodensity/ograf-studio/blob/stable/docs/USER_GUIDE.md).
For building from source, see the [development guide](https://github.com/zerodensity/ograf-studio/blob/stable/docs/DEVELOPMENT.md).
