# OGraf Studio 0.20

Released: 2026-09-10

- Mark rectangular or freehand areas directly on the canvas and give each area its own AI instruction. Hold the mouse button to draw freehand; release to select.
- Review AI proposals on the main canvas, compare with the original, and accept or reject in AI Assistant.
- Auto-keyframe protects against accidental animation. When off, object edits preserve existing motion without adding keys. Timeline Space play/pause is also fixed.
- Choose the thumbnail frame when exporting an OGraf package. MCP export supports the same frame choice.
- Updated MCP contracts and the authoring skill for these workflows.

Download `OGrafStudioServer.exe` for Windows x64; it includes the editor and MCP server.
The executable is unsigned. Checksums and build verification details are included with the release.
