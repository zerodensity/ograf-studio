# OGraf Studio 0.30.0

0.30 brings together the authoring and playout work since 0.22 and the 0.23 release candidates,
with a simpler keyframe workflow, plugin galleries, shared design tools and richer previews.

## Downloads and startup

- `OGrafStudioServer.exe` — Windows x64 standalone editor and MCP server.
- `OGrafStudioServer-linux-x64` — Linux x64 standalone editor and MCP server.
- `OGrafStudioServer-linux-arm64` — Linux ARM64 standalone editor and MCP server.
- `ograf-authoring.zip` — matching authoring skill.
- `RELEASE-MANIFEST.json` and `SHA256SUMS.txt` — source commit, build checks and artifact hashes.

Run the executable and open **http://127.0.0.1:4318/**. On Linux, first make the downloaded file
executable with `chmod +x <filename>`. Node.js, npm and Bun are not required on the playback machine.

The Windows executable is unsigned. Windows startup, HTTP, MCP and packaged assets and Linux x64
startup/HTTP are checked by the release workflow. Linux ARM64 is cross-built and checked for the
correct binary format and architecture; native ARM64 startup is not covered.

## Keyframes and text

- New objects start with a static pose. Animate individual properties with their diamonds;
  manual keys work with Auto-keyframe off. **At playhead** and **Whole animation** make the edit
  scope explicit, while ordinary Timeline playback runs continuously unless **Stop at Steps** is on.
- **Keys** and **Graph** are exclusive views with a shared ruler, zoom and scroll. Graph uses
  stable coordinates during a drag and commits one undoable time/value edit on release.
- Right-click empty Graph space for **Add keyframe here**. Position determines the frame and
  value; existing keys are never overwritten. Right-click a point or nearby curve to delete a key.
  Graph stays active after deletion, including the last key.
- **Reset [channel] animation** removes that channel's main and local-loop keys. Normal properties
  retain their sampled static value; reveal-only scale/clip channels return to neutral. Other
  channels, loop settings, bindings and Rules remain intact.
- Edit text directly on the canvas. Text presets include typewriter, fades, rises, flips, rolling
  digits and numeric count-up/down, with replay on data changes or custom actions.

## Media, sound and interactive Rules

- Paint objects and backgrounds with prerecorded media or named live inputs. Use a webcam to
  preview a live input locally, with camera settings and a separate presentation-background mode.
- Audition imported audio in Resources, then place **Sound Events** at Timeline frames. Advanced
  **Media Cues** share trim, loop, speed, volume and trigger controls, with named sources,
  clip/live switching, Cut/Crossfade and failure handling. They do not require audio/video tracks.
- The dockable Rules pane combines ordered conditions and actions across objects and groups.
  Use field comparisons, pointer/keyboard events, lifecycle events or custom actions to change
  visuals, animate shader parameters, trigger sound/media or control coordinated playout.
- Clocks and timers support on-air data-driven display settings, duration changes, custom-action
  controls and threshold alarms. Running and paused timer state is preserved during supported
  on-air setting updates.

## Plugins and charts

- The dockable Plugins gallery manages versioned `.ogsplugin.zip` chart renderers, animation
  preset packs and shader packs. Existing charts keep their exact renderer pins; applied motion
  becomes editable keys and shader presets become independent editable copies.
- Chart.js provides visual chart selection, editable/data-bound values, data-update animation and
  gradients, shaders or media on supported chart marks. Compatible animation packs can animate
  individual bars and slices, with separate In/Out choices and stagger.
- Shader packs share a live preview and support drag-and-drop to Fill, text Outline, Effect or
  Resources. Shader effects process the preceding stack output with their own blending controls.

## Shared design and coordinated playout

- Template Sets share fonts, resources and component sources. Master Brand Kits provide inherited
  tokens, named typography presets and rich background styles, with visible origins, local
  overrides and resets. Standalone child exports resolve their shared dependencies.
- Smart layout modifiers fit text, size and attach backings, hide empty content, arrange grids or
  rings, justify groups, face targets and follow paths. Their numeric controls can be animated or
  data-bound, using the same dependency-ordered evaluator in supported exported playback.
- The Transitions pane coordinates lanes, template replacement, shared-object morphing and make-room
  resizing. Incoming/outgoing motion can use authored, built-in or plugin animations. In-place
  data updates preserve the current on-air scene without retaking it.

## Preview, integrations and AI

- Single and coordinated exports include a self-contained HTML preview with Studio-style
  controls, left/right docking, exposed data and custom actions. Preview-only backgrounds,
  guides and FPS overlays help inspect the output without changing the graphic.
- **Preview FPS** measures browser animation-frame cadence; non-real-time **Render FPS** counts
  completed render samples. Neither reports the authored frame rate or GPU throughput.
- Exported OGraf pages can connect exposed fields and named live inputs to existing Nodos
  ElectroNode slots. Studio can keep selected templates updated as Nodos presets.
- A small web-player module hosts trusted exported graphics in tutorial websites, with lifecycle,
  data and custom-action methods. The built-in assistant adds model-aware context budgets and complete
  paged tool results instead of cutting large JSON responses.

## Compatibility

Media/audio and live interaction require real-time output; live tags need a compatible renderer.
Webcam devices, settings and footage remain local preview data. Coordinated exports retain their
own feature checks and restrictions, including media cues and unsupported Rule/loop side effects.
Chart capabilities depend on the installed trusted renderer; per-mark animation covers supported
bars/sectors, not line, area or radar marks. Compact template sets use archive schema 6; save a
compatible schema 5 copy when an older Studio reader requires it.

See the [User Guide](../USER_GUIDE.md) for workflows and compatibility details, or the
[development guide](../DEVELOPMENT.md) to build from source. Automated OGraf checks are not EBU
certification; verify the exported package in its intended browser, renderer and playout system.
