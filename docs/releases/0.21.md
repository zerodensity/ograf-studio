# OGraf Studio 0.21

Released: 2026-09-18

## What's new

- AI Assistant supports Codex sign-in and Anthropic API connections, with clearer setup instructions.
- Mark multiple rectangular or freehand areas directly on the canvas and give each area its own instruction, with optional voice dictation.
- Review AI proposals on the main canvas, compare with the original, and accept or reject changes in AI Assistant.
- Auto-keyframe protects against accidental animation while preserving existing motion. Timeline Space play/pause is fixed.
- Save transparent template thumbnails and choose the thumbnail frame when exporting OGraf packages.
- Embedded fonts render correctly in exported graphics, including fonts stored in custom package folders. Re-export existing graphics to include the fix.

Community contributions now target `dev`; maintainers promote tested changes to `main`.

Thanks to Cemal Demirci for the embedded-font fix ([PR #8](https://github.com/zerodensity/ograf-studio/pull/8)).

Downloads include single-file servers for Windows x64, Linux x64 and Linux ARM64, plus the authoring skill and checksums. macOS binaries are not included.
