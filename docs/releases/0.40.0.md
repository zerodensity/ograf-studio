# OGraf Studio 0.40.0

Export transparent WebM movies and PNG sequences directly from Studio, browse complete examples in
Project Explorer, and review how branding transfers between template sets. MCP adds video export
and reference-image comparison.

## Export

- **File → Export OGraf…** saves a ZIP package, standalone HTML, or both through one dialog.
  **NLE Export** prepares non-real-time output with a transparent composition background.
  [#93](https://github.com/zerodensity/ograf-studio/pull/93)
- **File → Export Video…** renders the current template as a VP9 WebM with optional transparency
  and timeline sound, or saves numbered PNG frames directly to a folder. Set output dimensions,
  Step hold duration, WebM bitrate, and optional black frames at either end. Studio shows export
  progress, the saved location, and the size of the last matching WebM export in the current
  session. [#104](https://github.com/zerodensity/ograf-studio/pull/104) ·
  [#109](https://github.com/zerodensity/ograf-studio/pull/109) ·
  [#110](https://github.com/zerodensity/ograf-studio/pull/110) ·
  [#111](https://github.com/zerodensity/ograf-studio/pull/111) ·
  [#112](https://github.com/zerodensity/ograf-studio/pull/112)
- Standalone and coordinated exports can set independent host output layers. Hosts that support
  the new manifest metadata can discover templates, slots, and public controls directly.
  [#88](https://github.com/zerodensity/ograf-studio/pull/88) ·
  [#89](https://github.com/zerodensity/ograf-studio/pull/89)

## Authoring and MCP

- **Project Explorer** brings searchable recipes and complete examples into File → New. Browse
  thumbnails and hover previews, check **License & Credits**, and open bundled or previously
  downloaded examples offline. [#90](https://github.com/zerodensity/ograf-studio/pull/90) ·
  [#91](https://github.com/zerodensity/ograf-studio/pull/91)
- **Brand Kit transfer review** lets you keep the source appearance, adopt destination branding,
  or bring source branding. Compare the result before applying and undo the whole transfer in one
  step. Sets with member-local Brand Kits use the v7 `.ogs` archive. Save standalone templates for
  collaborators on older Studio versions. [#96](https://github.com/zerodensity/ograf-studio/pull/96) ·
  [#97](https://github.com/zerodensity/ograf-studio/pull/97)
- **MCP** now advertises 23 tools and 79 operation names. Existing calls remain supported. Ask an
  agent to export a WebM or compare a capture with a reference image. The bundled authoring skill
  and setup guidance use the new tool names. [#117](https://github.com/zerodensity/ograf-studio/pull/117)

## Downloads and startup

- `OGrafStudioServer.exe` for Windows x64.
- `OGrafStudioServer-linux-x64` for Linux x64.
- `OGrafStudioServer-linux-arm64` for Linux ARM64.
- `ograf-authoring.zip` for the matching authoring skill.
- `RELEASE-MANIFEST.json` and `SHA256SUMS.txt` for source and download verification.

Run the executable and open **http://127.0.0.1:4318/**. On Linux, make the downloaded file executable
with `chmod +x <filename>` first. Use a current Chrome or Edge for media export. The Windows executable
is unsigned. The release workflow checks startup on Windows and Linux x64 and verifies the binary
format and architecture on Linux ARM64.

See the [User Guide](https://github.com/zerodensity/ograf-studio/blob/v0.40.0/docs/USER_GUIDE.md).
