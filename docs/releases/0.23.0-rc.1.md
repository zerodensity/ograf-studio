# OGraf Studio 0.23.0-rc.1

Development candidate for testing on `dev`. This is not the stable 0.23 release.

## What to try

- Build interactive graphics with ordered Visual Rules: combined conditions, field-to-field
  comparisons, hover and click events, playout triggers, cross-layer actions, delays, and visual
  transitions. Data and hover rules hold their results; event rules persist until superseded.
- Add Fade, Slide, Fly, or Focus **Animate In / Out** motion to selected layers. The presets write
  normal editable keyframes. The same operation is available through MCP as `set_layer_motion`.
- Use Typewriter, Fade in, Rise in, Pop in, and Word reveal text animations; replay them on a content
  update or custom action. Double-click text to edit directly on the canvas.
- Use Media fills and composition-level Sound Events and Media Cues for clips or renderer-owned live
  sources. Locally test a live tag with a webcam, or place the webcam behind a transparent graphic
  as an editor-only presentation background.
- Explore the reorganized Data and Rules panes, automatic field creation from Add Binding/Add Rule,
  clearer Preview & Export controls, and the Help menu's keyboard shortcuts.

## Downloads

- `OGrafStudioServer.exe` — Windows x64 standalone editor and MCP server.
- `OGrafStudioServer-linux-x64` — Linux x64 standalone editor and MCP server.
- `OGrafStudioServer-linux-arm64` — Linux ARM64 standalone editor and MCP server.
- `ograf-authoring.zip` — matching authoring skill.
- `RELEASE-MANIFEST.json` and `SHA256SUMS.txt` — source commit, validation record, and checksums.

The Windows executable is unsigned. Linux x64 receives a native startup/HTTP smoke test in the
release workflow; Linux ARM64 receives cross-build format/architecture checks but still needs an
ARM64-machine smoke test. The release workflow verifies the repository, dependencies, binary
formats, Windows startup and MCP, and uploaded asset digests before publication.

Media playback is real-time-only in this candidate. The webcam is a Studio preview source, not a
packaged video stream; exported live tags require a compatible playout renderer. Test codecs,
camera permissions, audio routing, GPU effects, and the target renderer before production use.
