# OGraf Studio 0.19

Released: 2026-09-10

- OGraf export ZIPs include a transparent `<id>_thumb.png` referenced in the manifest.
- Thumbnails use 320 × 180 pixels for 16:9 templates, with proportional sizing for other formats.
- The Save dialog adds previous/next-frame buttons and a fixed-size thumbnail preview.
- The canvas has a black border that stays one screen pixel wide at every zoom level.
- Timeline bands are borderless, 8px tall, and centered on the keyframe diamonds.
- Updated README screenshot, MCP contracts, documentation, and authoring skills.

## Downloads

- Windows x64: `OGrafStudioServer.exe`
- Linux x64: `OGrafStudioServer-linux-x64`
- Linux ARM64: `OGrafStudioServer-linux-arm64`

Run the executable and open http://127.0.0.1:4318/. Node.js, npm, and Bun are not required.
On Linux, first run `chmod +x <downloaded-file>`. Codex integration requires a separately installed,
signed-in Codex. Windows builds are unsigned. Windows and Linux x64 startup are tested;
Linux ARM64 is cross-compiled and structurally verified.

macOS downloads are temporarily unavailable, will be uploaded after few more tests.
