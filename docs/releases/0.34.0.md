# OGraf Studio 0.34.0

Share a live graphics preview across your local network while you continue editing in Studio. This
release also fixes authored Out animations, Arabic-script text animation, and masks on Auto Size
text.

## Shared Live Preview

- Open a template or coordinated template set to make its Live preview available at a fixed viewer
  URL. The standalone server prints the link and a QR code, and the same link follows the next
  template you open. [#75](https://github.com/zerodensity/ograf-studio/pull/75)
- Use **Sync viewers** to mirror the operator’s playout, pointer, and in-graphic mouse and keyboard
  interactions. Turn sync off to give each viewer independent playout and data controls.
  [#75](https://github.com/zerodensity/ograf-studio/pull/75)
- Reconnecting viewers recover the current playout state and the latest received data. The preview
  stays available while the Studio server runs, even after the editor closes. Studio Data
  Connections continue polling while the editor is open.
  [LAN preview guide](https://github.com/zerodensity/ograf-studio/blob/v0.34.0/docs/DEVELOPMENT.md#view-studios-live-preview-on-the-lan)

## Fixes and updates

- **Out animation** plays the full authored keyframe sequence when you take a graphic out from its
  final Step. The fix applies to live playback and scheduled rendering. Early and interrupted Out
  still blend from the current frame. [#82](https://github.com/zerodensity/ograf-studio/pull/82)
- **Arabic-script text animation** preserves joined letters, combining marks, and mixed text order in
  Studio and exports, including Urdu text. [#76](https://github.com/zerodensity/ograf-studio/pull/76)
- **Auto Size text masks** follow the measured text bounds as content or font size changes, keeping the
  text and its mask aligned in Studio and exports.
  [#74](https://github.com/zerodensity/ograf-studio/pull/74)
- Updated the bundled **Chart.js** engine to 4.6.1 and aligned the editor’s React and React DOM
  versions. [#71](https://github.com/zerodensity/ograf-studio/pull/71) ·
  [#72](https://github.com/zerodensity/ograf-studio/pull/72)

## Downloads and startup

- `OGrafStudioServer.exe` for Windows x64.
- `OGrafStudioServer-linux-x64` for Linux x64.
- `OGrafStudioServer-linux-arm64` for Linux ARM64.
- `ograf-authoring.zip` for the matching authoring skill.
- `RELEASE-MANIFEST.json` and `SHA256SUMS.txt` for source and download verification.

Run the executable and open **http://127.0.0.1:4318/**. On Linux, make the downloaded file executable
with `chmod +x <filename>` first. Use shared preview on a trusted LAN. The Windows executable is
unsigned. The release workflow checks startup on Windows and Linux x64 and verifies the binary format
and architecture on Linux ARM64.

See the [User Guide](https://github.com/zerodensity/ograf-studio/blob/v0.34.0/docs/USER_GUIDE.md).
