# Contributing

Use a short-lived branch per coherent change. Keep commits focused, preserve unrelated working-tree changes, and use pull requests for review when a remote is available.

Before requesting review or handing work over:

```bash
npm run verify
```

Update the current status, relevant decision record, known issue, and handover whenever the change affects them. Unfinished transferable work should be committed and clearly labelled as work in progress rather than hidden in a local stash.
